## Overall Impression

The homepage gets the hard, easy-to-get-wrong things right — a genuinely non-generic type pairing, disciplined design tokens, and a gold-rationing rule that's actually followed. What it gets wrong is largely self-inflicted: it ships the exact section-eyebrow pattern its own DESIGN.md forbids, its signature "Pour Ground" scroll mechanic was never built, real product photography sits unused on disk while every wine card renders an identical placeholder bottle icon, and there's no mobile navigation at all below 920px. The single biggest opportunity: reconnect the page to its own spec — the assets and rules already exist, they're just not wired up.

## What's Working

1. **Font selection actually did the work.** Spectral + Jost avoids every name on the reflex-reject list — the rarest thing to get right, and it's right here.
2. **The missing-image fallback SVG is correctly designed, just badly deployed.** `miniBottle()` is a branded silhouette, not a grey box, exactly per DESIGN.md's instruction — the problem is it's used for 100% of the catalog instead of the rare fallback it was built for.
3. **The gold-rationing rule is genuinely respected.** `--c-accent` gold appears only on price and badges on the homepage — verifiable adherence to a stated brand rule.

## Priority Issues

**[P0] No mobile navigation exists at all.**
- Why it matters: `.nav__links { display: none; }` below 920px with zero replacement — no hamburger, no drawer, no toggle markup anywhere. PRODUCT.md states desktop and mobile are used "เท่าๆ กัน" (equally); below 920px a visitor can only reach Catalog/About/News/Contact by scrolling all the way to the footer.
- Fix: Ship a mobile menu reusing the same disclosure pattern already built correctly for the catalog page's `.filters-sidebar`/`.filters-toggle-btn`.
- Suggested command: `/impeccable adapt`

**[P1] No product photography is wired to any wine, despite real assets existing.**
- Why it matters: `assets/img/wines/1.png`–`8.png` exist on disk; zero `WINES` entries reference an `img` field, so every card — including all four homepage-featured wines — renders the generic `miniBottle()` SVG. DESIGN.md principle #3 is literally "Show, don't describe."
- Fix: Wire the 8 existing PNGs to their matching wine ids now; source photography for the rest before this ships past prototype.
- Suggested command: `/impeccable harden`

**[P1] The homepage's signature "Pour Ground" mechanic was never built.**
- Why it matters: DESIGN.md's longest Named Rule describes a scroll-driven oxblood wash from white (hero) to full saturation (LINE band), capped at 0.28 opacity. No such layer, scroll listener, or opacity-scrub logic exists in style.css or site.js. Without it, actual oxblood coverage falls well short of the "30–50% of surface" Committed strategy PRODUCT.md calls for, and the page defaults toward the generic-white-catalog look the anti-references explicitly warn against.
- Fix: Implement the scroll-linked wash as specified, or if deliberately deprioritized for this prototype phase, update DESIGN.md so it stops describing a feature that doesn't exist.
- Suggested command: `/impeccable craft`

**[P1] The tiny uppercase tracked kicker appears above 5 of 6 homepage sections, violating the project's own explicit rule.**
- Why it matters: DESIGN.md bans this by name ("an eyebrow on every section is AI grammar"). It's shipped as the default section-header pattern site-wide.
- Fix: Keep at most one deliberate, named kicker as a brand device and replace the rest with weight/size hierarchy per the Weight-Contrast Rule already defined in DESIGN.md §3.
- Suggested command: `/impeccable quieter`

**[P2] Opacity-driven "muted" text likely fails the project's own WCAG AA mandate in several spots.**
- Why it matters: `.footer__copy { opacity: 0.3 }`, `.footer__list a` / `.footer__tagline` at `opacity: 0.5`, `.nav__links a` at `opacity: 0.65` — all alpha-blends rather than dedicated contrast-checked tokens, so effective contrast drifts with whatever's beneath. DESIGN.md principle #5 is "Legibility is luxury... WCAG AA ทุกจุด," and footer copyright text at 30% opacity against near-black is the likeliest failure point.
- Fix: Replace opacity-based dimming with dedicated `--c-muted`-style tokens computed to hit 4.5:1 against each specific background.
- Suggested command: `/impeccable audit`
